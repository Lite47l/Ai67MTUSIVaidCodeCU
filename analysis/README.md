# Сигналы стажировки A01

Аналитическое ядро принимает нормализованные ответы из `CONTRACTS.md` и возвращает список сигналов. Для запуска достаточно Python 3.10 или новее.

## Вызов из API

```python
from analysis import analyze_signals

signals = analyze_signals(
    responses,
    program_id="demo-a01",
    intern_id="DEMO-001",
    period=4,
)

priority = {"normal": 0, "attention": 1, "critical": 2}
status = max(
    (signal["status"] for signal in signals),
    key=priority.__getitem__,
    default="normal",
)
```

Передайте историю до выбранного месяца включительно. Если опустить `period`, функция вернет сигналы всей истории по возрастанию месяца. Для статуса в обзоре используйте сигналы выбранного месяца и отдельно считайте полноту ответов.

На каждый источник, стажера и месяц передавайте одну актуальную версию ответа. Пропущенной анкете соответствует отсутствие записи. В частичной анкете оставляйте `scores` и `comments` словарями. Значения пропущенных полей можно опустить или передать как `null`. Результат использует поля сигнала из `CONTRACTS.md` и готов к сериализации в JSON. При хранении сигналов после исправления ответа пересчитайте его месяц и следующий, поскольку два соседних месяца участвуют в правилах динамики.

В [эталонном JSON](../tests/analysis/fixtures/low_workload.json) есть синтетический ответ для API и ожидаемый результат для месяца 4. Этот пример можно использовать для проверки подключения A01.

## Правила анализа

| Вид сигнала | Условие |
| --- | --- |
| `low_score` | 1 или 2 по конкретному показателю, статус `critical`. |
| `borderline_score` | 3 при снижении к предыдущему месяцу, повторной оценке не выше 3 или комментарии о проблеме по связанной теме. |
| `score_drop` | Падение одного показателя на 2 балла и больше между соседними месяцами. |
| `repeated_issue` | Одна явная тема в комментариях два месяца подряд либо один показатель с оценкой 3 и ниже в обоих месяцах. |
| `score_disagreement` | Разница от 2 баллов между понятностью и пониманием задач. Для пары про команду дополнительно нужен комментарий о сложностях взаимодействия. |
| `text_issue` | Явное описание проблемы в выбранном месяце. При повторении темы за предыдущий месяц выдается `repeated_issue`. |

По умолчанию все перечисленные сигналы, кроме `low_score`, имеют статус `attention`. У каждого сигнала есть пояснение правила, оценки или дословные фрагменты, источники, месяцы и возможное действие HR.

Текстовый классификатор работает локально и распознает распространенные русскоязычные формулировки о задачах, обратной связи, нагрузке и общении с командой. Простые отрицания и явные формулировки об улучшении отсеиваются. Ирония, сложные отрицания и непривычные формулировки могут привести к ложному сигналу или пропуску. Числовые правила выполняются независимо от результатов анализа комментариев.

```console
python -m unittest discover -s tests/analysis -v
```
