# МГТС «Код города» — рабочий старт команды

Сейчас в репозитории находятся проверенный аудит, контракт и задачи. Исполняемый прототип еще не интегрирован. Исходные `docx/xlsx` лежат на компьютере команды в родительской папке и не публикуются в Git.

1. Откройте [TASKS.md](TASKS.md), затем [CONTRACTS.md](CONTRACTS.md).
2. Каждый участник забирает свой промпт из `prompts/`: `oleg_codex.md`, `egor_codex.md`, `rezvan_codex_figma.md`, `masha_claude.md`.
3. Создайте собственную ветку от `codex/discovery-and-contracts`; передайте координатору ветку, SHA, результаты тестов и блокеры.
4. Публиковать ссылку на прототип и инструкцию запуска здесь можно только после сквозной проверки. До подключения двух форм не утверждайте, что внешняя интеграция работает.

Основной путь сдачи: импорт 60 исторических ответов → аналитика и UI → две внешние формы → новый ответ автоматически обновляет профиль и сигналы → проверка дубликатов и evidence → защита.
