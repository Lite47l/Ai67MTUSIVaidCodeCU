## Расхождения и решения по API

- POST /hr/enrollments отсутствует в актуальном dev. Участник создаётся первой доверенной внешней анкетой.
- Общий профиль продолжает возвращать ai, ruleSignals и timeline другим ролям. Интерфейс скрывает внутреннюю аналитику. Серверную выдачу должен согласовать и исправить владелец backend.
- Поле наставника attention возвращается стажёру. До согласования интерфейс скрывает «Ситуации для внимания» в его кабинете.
- conversationPlans и hiddenSignals находятся на верхнем уровне профиля. Они уже присутствуют в актуальном dev.
- Конфигурация сервиса подтверждает настройку. Доставка подтверждается событием accepted. API выдаёт только последние 50 событий, более ранняя доставка может отсутствовать в этом срезе.
