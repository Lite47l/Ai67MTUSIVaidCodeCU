# Контракт Go и Python

Версия `1.0`. Go является владельцем ответов, прав доступа и истории. Python получает историю одного стажера и возвращает только производный анализ. Нельзя менять исходные ответы, выдавать инструкции из комментариев за системный промпт или передавать модели секреты.

## Запрос

`POST /v1/analyze`, JSON, `Authorization: Bearer <AGENT_TOKEN>`, `Idempotency-Key: <requestId>`.

```json
{
  "schemaVersion": "1.0",
  "requestId": "analysis:<64 hex characters>",
  "revision": "<64 hex characters>",
  "programId": "mgts-internship",
  "internId": "СТ-004",
  "history": [
    {
      "eventId": "history:intern:СТ-004:4",
      "programId": "mgts-internship",
      "internId": "СТ-004",
      "department": "HR-блок",
      "month": 4,
      "source": "intern",
      "scores": {"taskClarity": 5, "mentorSupport": 5, "workload": 2, "interest": 5, "development": 5, "teamwork": 5, "satisfaction": 4},
      "comments": {
        "difficulties": "Нагрузка была слишком высокой из-за нескольких проектов одновременно.",
        "barriers": "Основная сложность — высокая нагрузка; по задачам и взаимодействию проблем нет."
      },
      "receivedAt": "2026-11-26T00:00:00Z"
    }
  ]
}
```

Пример сокращен до одной записи, время иллюстративное. В реальном запросе до 12 записей, отсортированных по месяцу и источнику. `mentorId` есть только у ответов наставника. `raw` не передается. `revision` — SHA-256 списка канонических хешей ответов, вычисляет Go; Python возвращает значение без пересчета.

## Ответ

HTTP 200:

```json
{
  "schemaVersion": "1.0",
  "requestId": "analysis:<64 hex characters>",
  "revision": "<same revision>",
  "summary": "В месяце 4 отмечена высокая нагрузка. Нужно проверить ее распределение.",
  "signals": [{
    "id": "workload-m4",
    "kind": "workload",
    "severity": "critical",
    "title": "Низкая комфортность нагрузки в месяце 4",
    "evidence": [{"eventId": "history:intern:СТ-004:4", "field": "workload", "value": "2"}]
  }],
  "recommendations": ["Обсудить распределение параллельных задач со стажером и наставником."]
}
```

Учитывайте всю историю: нагрузка СТ-004 восстановилась в месяце 5. Исторический сигнал не означает текущую проблему; резюме должно различать их. `severity` — `positive`, `attention`, `critical`. `signals` и `recommendations` обязательны, даже если пусты. Каждый сигнал имеет минимум одно доказательство. Для оценки `value` — строка числа; для комментария — полный исходный текст, без пересказа или обрезания. Поле — ключ из `scores` или `comments`. Поля, источники и периоды берутся из указанного `eventId`.

Go проверяет версию, идентификаторы запроса и ревизии, размеры ответа, наличие массивов, уникальность ID сигналов, уровни важности и точное совпадение evidence с историей. Это проверка происхождения доказательств, не доказательство семантической правильности вывода модели.

## Отказ и повтор

Таймаут одного вызова — 25 секунд. Четыре попытки, задержки 2/4/8 секунд перед следующими попытками; после четвертого отказа `failed`. HR может повторить запрос. Не возвращайте HTTP 200 при ошибке модели. Ограничение ответа — 1 MiB.

Повтор с тем же requestId и тем же содержимым возвращает прежний результат; измененный повтор — 409. В адаптере Python кеш ограничен 128 результатами в памяти, поэтому после перезапуска вычисление может повториться. У настоящего агента сохраните результаты в постоянном хранилище и ограничьте время модели менее чем 25 секундами. Не используйте внешний побочный эффект внутри анализа.

Очередь Go сохраняется в SQLite. При старте `running` возвращаются в очередь, актуальные истории сверяются с заданиями. Старое задание до вызова помечается `superseded`; старый ответ после изменения истории не показывается пользователю. Поддержан один процесс Go; горизонтальное масштабирование требует атомарного захвата задания и lease.

`/docs` Python-сервиса содержит интерактивную спецификацию. JSON Schema: `agent-request.schema.json`, `agent-result.schema.json`. Автоматический тест реального HTTP-обмена и отбраковки ошибочного evidence находится в `internal/pulse/pulse_test.go`.
