# Приемка

1. Импорт из двух предоставленных файлов создает ровно 30 ответов стажеров и 30 наставников, 5 ID и 6 периодов; повторный импорт не меняет счетчики.
2. Для каждой записи ID, подразделение и период валидны; числовые поля в пределах 1–5; неизвестное поле и повтор события с измененным телом дают явную ошибку.
3. Обзор показывает полноту ответов по каждому источнику, выбранный месяц и приоритетную очередь; отсутствие ответа не становится оценкой 0.
4. Профиль СТ-004 за месяц 4 показывает нагрузку 2/5, точный комментарий, источник и восстановление до 4/5 в месяц 5; СТ-003 и СТ-005 демонстрируют повтор и последующее улучшение без ложного «текущего кризиса» в месяце 6.
5. Две реальные формы отправляют тестовые ответы, которые автоматически попадают в систему с проверенным ID/периодом, сохраняются и изменяют API/UI. Повторная доставка не создает дубликатов. Ошибка доставки видна и может быть повторена.
6. Каждый сигнал содержит источник, период, показатель/цитату и понятное правило; «проблем нет» не классифицируется как проблема.
7. Без LLM API числовые сигналы, история и UI продолжают работать. Демонстрация воспроизводится из README без ручной правки БД.
